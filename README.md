### 📊 Project Overview
This project visualizes the growth and performance of the Electric Vehicle market in India.
- **Dataset:** 3.4 Million+ EV Sales Records
- **Tools Used:** Tableau, Excel, Data Cleaning
- **Focus Areas:** State-wise adoption, Manufacturer market share, Yearly trends, Vehicle category analysis

### 🔍 Key Insights
- Identified top 5 states driving EV adoption
- Analyzed YoY growth rate of 2W, 3W, and 4W EV segments
- Manufacturer-wise market dominance (e.g., Ola, TVS, Bajaj)
- Seasonal trends and policy impact

### 🛠️ Dashboard Features
- KPI Cards: Total Sales, Market Share
- State-wise Choropleth Map
- Manufacturer Performance Bar Chart
- Time-series Trend Analysis
